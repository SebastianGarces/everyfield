# Assessment consistency and publication

Plant Intelligence and Network Intelligence retain different rubrics and authorized projections. [Methodology requirements](../product/methodology-intelligence.md) define evidence meaning and formulas. The intelligence producer owns consistent inputs, freshness and publication. Default storage and execution choices follow [Everyfield patterns](intent://local/note/df294729-367b-493b-9faf-654cf6b25b62).

## Stored identities

Each run retains its demand, exact immutable captured input, source/reference provenance, as-of instant, validated findings and known outcome. Material, daily, manual and operator requests remain distinguishable. Organization results retain protected lineage to exact source plants, released assessments and current recognition/sharing. Reader feedback belongs to its original account and requires an entitled target.

Current reads return the latest still-authorized complete result with deterministic ordering. Incomplete, deferred or failed work never displaces a valid prior result. Historical results retain exact original evidence while every read checks current rights. The implementation chooses how to locate the current result.

## Assessment freshness

Every committed assessment-relevant change makes affected work stale across native, Evry, import, correction, merge, removal and system writers. Failed changes, exact retries, real no-ops and unrelated fields do not create new assessment evidence. Fact changes and their freshness consequences succeed or fail together.

WP-040 proves freshness coverage for every actual input consumed by the fact builder, including conditional inputs. Relevant input changes refuse stale publication; rollback preserves both facts and eligibility. The proof tests these outcomes without requiring database triggers, a counter column or a writer registry.

Organization publication depends on current affiliations, category grants, contributor inputs and released source assessments. Changed or revoked inputs cannot leave an affected result eligible, and invalidation reveals no raw plant roster. Current reference activation is an independent publication condition. Private care, its existence, calendars, corrections, nudges and support questions remain excluded from inputs and freshness.

Lost wake-ups do not lose owed assessment work. Refresh covers never-assessed plants, changed sources/references and complete results at least seven days old. Daily UTC refresh windows allow quiet time-dependent evidence to receive a new fixed as-of instant even without fact changes. Launch countdown and attestation ages use that instant and the saved local calendar.

## Snapshot and model boundary

Capture all typed facts, source state, current reference activation and one as-of instant consistently. Concurrent changes cannot produce mixed old/new input. Preserve exact captured input and provenance before model work. Provider latency cannot hold up unrelated changes. A new time/input snapshot is a new run; retries reuse only an exact still-eligible snapshot.

Organization input uses released plant results under exact current recognition, category and geography predicates. Each pattern needs two distinct eligible contributors at its geographic level. Protected lineage stays server-only. The model receives permitted aggregates, windows, quality flags and structured concern counts with the separate portfolio rubric. Bounded named rows are attached by the server under current rights. Raw Person/interview/four Cs/private notes/street addresses and private-care metadata never enter NI input.

PI model-purpose projection drops raw human interview/four Cs scores, judgment, qualification, result, notes and testimony even when a native People read was authorized. It retains only operational evidence and allowed human-record presence/count/date. Removed raw content cannot become a hidden summarized finding. Missing data, false and measured zero remain distinct. Cite actual occurrence, original denominators and immutable formula versions; storage creation time is not evidence of human contact.

## Execution and budgets

Assessments cannot publish after losing execution ownership. Each provider call has a 45-second maximum. Count every dispatch, including SDK retries, against at most four provider attempts per draft and three output drafts. The cumulative run budget is 60,000 input and 12,000 output tokens, including uncertain charged calls. Deadline or budget may stop work earlier. Retry-After is respected without running past the deadline. Lease and renewal details belong to the patterns.

Exhausted invalid drafts fail with the final draft's actual violations. Availability/budget limits defer with a due instant. Lost claims retain safe attempt evidence; a replacement worker may resume only within the same eligible budget or create a new run. Three exhausted scheduled attempts require operator review until a new material/reference/time demand or authorized retry. Diagnostics omit raw inputs/outputs and protected manifests.

Retrieval failure may leave deterministic facts visible with degraded-grounding status and the last valid result's age. It cannot publish ungrounded advice, invented citations or a successful empty/healthy result. Missing mandatory reference fails. NI uses its own whole pinned rubric; schema-valid output alone does not prove semantic truth.

## Publication and current reads

Publication succeeds only while source inputs, current reference activation, rubric/policy, execution ownership and lifecycle remain eligible. Organization publication also requires current recognition, category grants and unchanged contributing source facts. Deletion or access suspension blocks publication. Validated facts, formulas, citations, denominators, field permissions, complete results and required notices succeed or fail together.

A changed fence marks the attempt superseded and leaves newer work eligible, without publishing or notifying. Matching data cannot authorize an expired worker. A reference rollback has a new activation identity and rejects workers from either old activation. Failed postcommit wake-up cannot demote a completed result.

Every current/history/export/cache/Evry read reauthorizes contributors. Revoked input withholds the affected whole result or permits a genuinely recomputed projection; removing a name from prose is not recomputation. Shared-findings OFF may retain independently allowed identity/link and Not shared. Ended identity/page reach removes the row. Reads call no model. At source plant purge, all affected mixed runs, facts, findings, contributors, linked feedback and copied artifacts purge; an organization's ownership cannot preserve the deleted source body or reset its copy expiry.
