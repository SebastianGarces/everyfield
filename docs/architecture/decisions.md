## Shared contract freeze procedure

C0 follows WP-002: IDs, actor context, error envelope, calendar/instant types, request idempotency shape and authorization test harness. C1 follows WP-006/WP-008/WP-011: identity/tenancy/people schema and object grants. C2 follows WP-022/WP-023/WP-025/WP-038: attendance/follow-up/task/phase transitions, domain event payloads and revision semantics. C3 follows WP-041/WP-042/WP-053: rubric publication identity, AI outputs and approved Evry plan digest/execution policy. Freezes are contract versions, not bans on improvement: incompatible changes require consumer impact list, revised tests and coordinated merge order. Only the designated schema/contract owner edits shared contracts and migrations; lane owners request reviewed changes.
