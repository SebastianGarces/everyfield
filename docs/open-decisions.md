## Evidence limits

This plan inspects local source and tests; it does not query production databases, run live provider requests, inspect secrets, execute migrations or test v3 runtime. The full database catalog may include history beyond declared schema, so schema counts describe checked source, not a certified live catalog. Main is dirty in unrelated marketing/skills files, recorded in the source manifest; alpha is clean. The diagnostic branch adds accurate attribution of the last rejected AI draft, not new methodology. The historical Google Doc was reviewed by the parent on October 1; its unresolved comments are historical evidence and do not undo later repository dispositions.

Automated evidence manifests establish which files/symbols were inventoried. They cannot prove every semantic edge case works. Unmapped files, unresolved consumers and unapproved reference currentness are explicit review items, never inferred as dead merely because they are absent from navigation.
