# Tiptap's free UI components, vendored

These files come from Tiptap's free, MIT-licensed UI component repository
(https://github.com/ueberdosis/tiptap-ui-components, license: https://github.com/ueberdosis/tiptap-ui-components/blob/main/LICENSE).
It is the source of the free `simple-editor` template (https://tiptap.dev/docs/ui-components/templates/simple-editor).
Source commit: `799929bea4804c73767562b69f8acc2acdb8ac86` (main, 2025-10-07). Nothing here comes from a paid plan:
no `@tiptap-pro/*` package, no Start-plan component such as the slash dropdown menu, no registry token. A test
(`tests/unit/documents/editor-schema.test.mts`) fails on any non-MIT `@tiptap/*` package, any `@tiptap-pro/*` package and any
Tiptap registry line in an `.npmrc`.

Every copied file keeps Tiptap's code apart from the Everyfield changes listed here. Some are the same in each: imports point to this folder, the SCSS
imports are gone and the class names are Tailwind strings from `styles.ts` (made of `packages/ui` tokens), the
`@radix-ui/*` imports read the `radix-ui` package the app already uses, and Tiptap's SVG icons are the product's
Hugeicons (`icons.tsx`). Extra changes are listed per file.

Everyfield also removed what nothing in the product uses, in every copied file: the mobile hook (`use-mobile.ts`) and
its `data-mobile` attribute; the attributes no style or code reads (`data-style`, `data-variant` and the toolbar's
`variant` prop, `data-focus-visible`, `data-tooltip-state`); the standalone `LinkContent`; the shortcut badges
(`MarkShortcutBadge`, `ListShortcutBadge`, `BlockquoteShortcutBadge`, `HistoryShortcutBadge`) with the `showShortcut` and
`text` props that drew them next to the icon; and the `hideWhenUnavailable`, `onToggled`, `onExecuted` and `onSetLink`
options with the code only they fed. A toolbar button writes `data-disabled` only while it is off
(`data-disabled={!x || undefined}`): Tiptap writes `data-disabled="false"` on an enabled button, and the `data-[disabled]`
classes and the controls' `[data-disabled]` cursor rule match the attribute whatever its value
(`tests/unit/documents/toolbar-disabled.test.mts`).

Tiptap has no free ready-made component for the combined text-style menu (paragraph styles and headings in one
menu), the tag label, the block insert menu or the move and delete controls. `../Toolbar.tsx` builds those from the
same primitives (button, dropdown menu, toolbar). The lists and the quote use Tiptap's ready-made buttons.
